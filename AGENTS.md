# St Columb's College learning platform
This private repository is the canonical codebase. Read README.md and this file before edits. Inspect latest main before changes; use branches and pull requests for substantial changes, test, and commit. Do not replace the site with an unrelated prototype or silently remove existing features.
## Established product decisions
- Branding: St Columb's College, navy #14284B, blue #244C92, gold #E9C34B, cool grey #F3F5F9. Proposed school-inspired colours, not official brand verification.
- Every new visit starts with role selection. Student demo sign-in is not real authentication. No Irish subject pages.
- Spanish > Assessment 1 > Los sustantivos — Everyday Nouns: 30 terms, full vocabulary list below study dashboard, starred filter, original order or mastery sorting.
- Stars are shared across study modes, independent of mastery. Flashcards have independent rounds: Know it removes term from future flashcard rounds, not Learn mastery. Next/previous, flip, language direction, shuffle and starred-only scope must work. Study options must not reset progress; distinct scopes retain sessions.
- Learn: up to six distinct unmastered terms per round, two correct answers including written recall. First correct recognition moves to Familiar; correct written recall moves to Mastered and removes term from queue. Incorrect written recall returns term to Remaining. Corrections do not count. No predetermined final round; completion only when queue empty. Progress = (2*mastered+familiar)/(2*selected count), not number of rounds. Preserve language direction and session state; starred-only supported. Test settings must be configurable and results shown after submission.
- Maths: CCEA GCSE M1 foundation calculator. Several questions at once, printable worksheets, photo/PDF submissions, question-specific rubrics, positive marking, method/accuracy/combined marks, alternative methods and follow-through where appropriate. Unreadable work must be flagged, not guessed. AI tutor and marking require a real server-side API connection; never simulate live marks. AI feedback is formative, not official grades. Validate generated maths independently. The starter generator is not exhaustive M1 coverage.
- Staff modules are deliberately mapped interface previews: My classes, learning resources, scanned assessment marking, assessment feedback builder, practical room/equipment planner, cover handover, parent information publisher, sixth-form course comparison, exam notice checker. Roles: student, teacher, technician, parent/carer, office, careers, exams officer, administrator. Preserve navigation. No real records or messages submitted by previews.
## Security and development
- Never commit API keys, identifiable pupil data, uploads, private school documents or exam reference PDFs/text without appropriate authorisation. Use environment variables for secrets. No production deployment until authentication, authorization, data protection, safeguarding, teacher review, storage/retention and rate limiting are implemented.
- Preserve existing browser storage keys where practical. Browser storage is not a school database. Verify Spanish, Maths, and all role navigation after modifications.
- Do not claim a feature is implemented if it is only a UI preview. Record new decisions and limitations in docs or README.
